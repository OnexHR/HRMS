# Frontend

React + TypeScript + Vite frontend for the HRMS monorepo.

- Styling: Tailwind CSS v4 via `@tailwindcss/vite`
- Routing: React Router
- Forms/validation: React Hook Form + Zod
- HTTP: Axios
- Icons: Lucide React

## Scripts

```cmd
npm run dev
npm run build
npm run lint
npm run preview
```

Run from this directory or from the repository root with `npm run dev:frontend`.
